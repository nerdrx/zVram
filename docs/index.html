The current prototype

Two paths. Clear boundaries.

01 / TELEMETRY

See allocation behavior

An opt-in Vulkan layer records AMD RADV device-memory allocation activity and applies an explicit overallocation policy when the driver supports it. The native driver may place allowed overflow allocations in system RAM.

Vulkan layerAMD RADV
02 / COMPRESSION

Test managed buffers

A CPU zstd proof explores compression on buffers the application explicitly manages. It does not intercept or compress arbitrary application memory.

CPU zstdExplicit buffers
