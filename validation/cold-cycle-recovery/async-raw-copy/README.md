# Async readback storage copy

The async snapshot path now reserves raw storage before alias handoff, then assigns GPU-completed mapped bytes into that reserved vector. This avoids zero-filling payload bytes immediately overwritten. The vector remains locally owned through off-lock encoding; failed assignment returns only after existing private-view unbind and app-alias rebind. CPU13 checks and both deterministic realGPU encode-overlap/admission/cap-raise-discard gates pass. Every pressure fixture verifies complete bytes after cap raise and clean teardown.
