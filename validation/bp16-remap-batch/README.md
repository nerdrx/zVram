# BP16 batched sparse-remap fixtures

The four-frame BP16 restore/remap fixtures passed CPU, synthetic, and native
full-byte gates. Each fixture requires one submitted sparse remap transaction
for the four child frames, zero GPU restore fallback, and no validation
diagnostics. The opt-in model run and its limits are recorded in the
[full-model archive](../internlm-bp16-gpu-remap-batch-cold26-owner26-resident19-lfu/README.md).
